# 早期初始化与渲染实验记录

归档日期：2026-11-03。本文摘录清理前的历史交接记录，保留实验方法和已报告数值；当前使用方法见 [best_pipeline.md](best_pipeline.md)，后续联合优化及四组重采样消融见 [resampling_ablation.md](resampling_ablation.md)。历史方案的专用代码、模型、图像和缓存均已删除。

以下实验主要使用房间的四个验证相机，部分相机参与了参数选择。各阶段的背景、前景阈值、轮廓排除和滤波口径存在变化，只能在同表口径下比较，不能与后续 16 个独立测试视角直接比较。未实施的高阶 SH／完整 BSDF 方向不作为实验结果。

## 连续表面采样

早期 CUDA 转换按三角形面积分配高斯，用面最长边确定统一的切向尺度；细长三角形会产生极端轴比。连续表面方法按精确几何邻接、法线角度和 UV 连续性构建 chart，隔离薄片、硬边和材质／UV 接缝；沿实际最长边递归分区，分层采样中心，依据同 chart 邻域估计切向足迹并施加边界约束。法向厚度为短切向轴的 2%，颜色按 Mesh UV 查询。

房间含 2,494 个网格对象、4,936,252 个三角形。以下同为 10,701,421 个高斯，固定种子 3089248367，四视角等权平均；覆盖与深度排除了参考轮廓附近 3 像素，BaseColor PSNR 使用完整前景。

| 指标 | 旧尺度修复基线 | 连续表面版本 |
| --- | ---: | ---: |
| 不透明覆盖（alpha ≥0.95） | 78.10% | 99.84% |
| 深度一致覆盖 | 35.72% | 93.88% |
| 深度 MAE | 83.97 cm | 3.05 cm |
| 深度误差 P95 的四视角均值 | 406.90 cm | 9.41 cm |
| 深度轮廓 F1（2 像素容差） | 0.242 | 0.818 |
| BaseColor PSNR | 14.99 dB | 22.21 dB |

同预算、同边界／尺度规则下，由重心格点改为实际最长边分区后，第一视角内部覆盖从 97.33% 提升至 99.47%，四视角轮廓 F1 从 0.736 提升至 0.818。该阶段初始化约 201.5 秒，源 Blend 哈希保持一致。当时通过 30 项测试；该数量属于历史记录。

## 渲染口径与屏幕滤波

使用解析平面、两层遮挡和棋盘作受控对照，仅切换线性／显示颜色合成时 alpha、深度逐位不变。线性黑白平均编码为 sRGB 是 0.735357，直接平均 sRGB 是 0.5。真实室内同一 PLY 改用线性合成后 PSNR 从 22.206 变为 22.332 dB，RGB MAE 从 0.02947 变为 0.02980；颜色空间正确并不保证跨纹理足迹误差降低。

同一最终 PLY、classic 渲染中，将 eps2d 从 0.3 降至 0.05，PSNR 从 22.309 升至 25.045 dB，深度 MAE 从 2.827 降至 2.016 cm。classic 对小高斯的最小屏幕协方差会放大足迹及 alpha 贡献，影响薄结构、遮挡和纹理。

当时比较 classic 的 eps2d=0.03／0.05／0.1／0.3 与 antialiased 的 0.03／0.1／0.3。antialiased 最高约 26.00 dB，但覆盖／轮廓较弱。在覆盖 ≥99.8%、轮廓 F1 ≥0.818、深度 MAE 不高于初始值的约束下，选择 classic、eps2d=0.05。这是四室内相机上的参数选择结果。

解析倾斜面还说明 Gaussian 期望深度与 Mesh 首交深度不同：在约 2.08 cm 间距、切向 sigma=0.8 倍间距时，正对平面深度 MAE 约 2.93e-7 m，45°／75° 平面约 1.24／2.16 cm，两层遮挡边缘约 35.19 cm。中心位于平面也不能消除足迹内中心深度及层混合的误差。

## 自适应密度与方向支撑

纹理梯度在 scene-linear RGB 中计算，并通过 UV-to-world Jacobian 转换为每米颜色变化，mip 层随世界间距选择；面积探针和递归分层用来识别局部高频。曲率按流形边两侧法线夹角除以跨边的实际距离估计；窄片用面积／周长近似宽度，补偿小书脊和细杆预算。整数预算由面积、纹理／曲率重要性及边界共同分配。

尺度在同 chart 邻域中估计八个切向方向的 Voronoi 支撑，方向缺口时扩大邻域，避免密集行／稀疏列被平均间距限制压扁。边界限制 2 sigma，曲率限制足迹内法线转动。纹理结构张量可使高频方向变窄，但旋转／拉伸必须与实际密度及几何支撑匹配。

早期联合校准在解析倾斜面、半棋盘／半平色面及前后遮挡上搜索 324 组间距、纹理权重、重叠、轴比和光学厚度。合成校准集 PSNR 从 19.512 到 20.529 dB，平均深度 MAE 从 0.905 到 0.825 cm，边界泄漏从 0.05274 到 0.04981。该校准集参与参数选择，不属于独立测试。

以下四视角均采用线性合成、classic、eps2d=0.05。

| 指标 | 仅校准渲染 | 纹理／曲率采样 | 联合校准配置 |
| --- | ---: | ---: | ---: |
| 高斯数 | 10,701,421 | 13,556,630 | 18,924,395 |
| BaseColor PSNR | 24.277 dB | 24.959 dB | 25.045 dB |
| 不透明覆盖 | 99.738% | 99.683% | 99.806% |
| 深度一致覆盖 | 96.877% | 97.183% | 96.918% |
| 深度 MAE | 2.359 cm | 2.017 cm | 2.016 cm |
| 深度轮廓 F1 | 0.811 | 0.813 | 0.833 |
| GPU 光栅化时间 | 35.32 ms | 44.41 ms | 58.23 ms |
| PyTorch 分配峰值 | 1.63 GiB | 2.06 GiB | 2.84 GiB |
| CPU 初始化时间 | 201.5 s | 391.0 s | 913.2 s |

这些历史 GPU 时间是光栅化耗时，不是后续 1500 步的优化时间。增加到 1,892 万点的整体 PSNR 收益约 0.087 dB，深度一致覆盖略降；不能把增加预算解释为所有指标改善。

未保留的纹理拉伸变体约 1,892 万点、重叠 0.7、纹理因子 1.5，四视角平均覆盖仅 98.88%、轮廓 F1 约 0.762。方向性邻域压力测试中，0.01 m 行距、交替 0.05／0.15 m 列间隙使固定近邻数与平均间距限幅失效；扩大方向邻域后，同点数覆盖从 48.03% 到 100%、平均 alpha 达 0.9994。它证明该例中的支撑估计缺陷，不是任意不均匀分布的保证。

另一速度配置约 982 万点，GPU 光栅化 35.89 ms、PyTorch 峰值 1.56 GiB，但室内深度 MAE 增至 3.27 cm、轮廓 F1 降至 0.801。它未作为质量方案保留。

历史不透明度校准用局部代表面积与椭圆光学质量建立先验，再按覆盖选择参数；最终所有 opacity 均触及 0.995 上限，实际没有得到逐点变化的 opacity。当时通过 44 项测试，包括真实 CUDA 的颜色／深度合成、平面覆盖与不均匀行列覆盖。

当前原方案保留必要的连续表面／自适应初始化与渲染实现，随后用联合 Mesh／图像 loss 优化；这些早期参数搜索和变体入口不再维护。完整 BSDF、源材质 Alpha、法线贴图、镜面和高阶 SH 未由这些实验验证。
