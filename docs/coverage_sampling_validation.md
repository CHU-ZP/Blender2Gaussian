# 覆盖采样渲染验证

日期：2026-11-04。实现入口与完整设计见 [coverage_sampling.md](coverage_sampling.md)。浏览 [Mesh／旧初始化／新采样对比图](../outputs/coverage_validation_20261103/gallery.html)，完整协议、模型哈希、探针与指标见 [coverage_sampling.json](validation/coverage_sampling.json)。

## 范围与协议

实验包含平面、带孔平面、3 毫米薄片、棋盘纹理，以及两个源场景中独立复制的真实构件。房间构件为 `G-Obj3d66-1077`，家具构件为 `candidate_004/Caster_0_fork_yoke`。每个真实构件的全部求值三角形均纳入目标，没有只保留正面或抽取部分纹理面。原源 Blend 和两个 best 模型的 SHA256 与保留记录一致，见 [核对报告](../outputs/coverage_validation_20261103/preservation_report.json)。

真实构件按可见、带图片纹理、6–300 个原多边形、包围盒对角线 0.03–0.6 米、UV 跨度不超过 2 筛选，再按多边形数量与名称排序。筛选只定义近景实验范围，采样器没有点数上限。相机朝向最短主轴，以展示主要表面；来源、UV 范围和相机基保存于各 `source_selection.json`。

每个案例使用正面、斜视、近景三个相机，共 18 个配对视角；每个视角分别保存 Mesh、旧采样和新采样 RGB／alpha／depth。分辨率 640×480，gsplat classic、eps2d=0.05、A100 GPU 1；Mesh 为无光照不透明 BaseColor，两种高斯使用相同光栅化与线性白背景合成。比较对象是初始化模型，未运行联合训练，也未重建两个完整场景。

质量协议为空间覆盖下界 0.95、构造探针目标 0.98、opacity 0.99、有效半径 3σ、最大物理间距 0.024 米、边界误差带 0.001 米、平面误差 0.0001 米。**本次颜色容差为 scene-linear RGB 的 0.08；生产默认仍为 0.02。** 更小颜色容差可能自然生成更多高斯。

完整前景指标包含所有 Mesh alpha≥0.99 且深度有效的像素，边界也参与统计；轮廓带不再从这个指标中排除。高斯 alpha≥0.95 计为覆盖。Mesh 亚像素抗锯齿过渡带没有被当作不透明前景；几何连续覆盖另用源三角形证书检验，不能由屏幕统计代替。普通高斯尾部与屏幕滤波的漏出在投影后的世界误差带之外单独测量，阈值为最大 alpha≤0.05。

## 边界与纹理修复

房间面板的初次模型虽通过连续几何认证，近景轮廓带之外仍出现最大 alpha 0.113245。定位到多个长而窄的高斯在角点外叠加普通尾部，屏幕滤波进一步放大贡献。最终构造把边界安全半径从 3σ 增至至少 4σ，覆盖认证仍使用 3σ；补采样重新满足原覆盖要求。修复后生成 10,866 个高斯，全部三个视角的带外最大 alpha 为 0，完整前景与边界覆盖均为 100%；初始化、导出与认证共 378.01 秒。原模型、渲染和指标保存在该案例的 `*_before_tail_guard` 路径下，阈值和相机未变。

其他五个保留实验模型在这次安全半径调整之前生成，已经通过相同覆盖与渲染验收；最终报告逐案例记录构造半径和模型哈希。使用最终代码从头生成所有案例时数量可能不同，停止条件仍由质量决定。

纹理修复还解决了两种过度收缩：只沿未满足颜色界的 UV 方向收缩，避免反复缩小已经足够细的轴；先检查完整足迹的精确颜色界，再按梯度修复，避免低幅度高频噪声强制微米级采样。最终颜色检查使用周期双线性纹理的精确矩形极值，包含实际可能相交的所有 UV 连续源面。

## 成本与未完成压力测试

棋盘模型生成 29,866 个高斯和 502,159 个连续证书单元，初次采样、导出与复核合计约 820 秒，其中采样约 662 秒。旧受控案例报告中的 `seconds` 来自最后一次复验，不能当作冷启动成本；新运行分别记录 `initialization_seconds` 和 `revalidation_seconds`。数量、耗时与证书规模都是满足质量的结果，没有通过截断限制它们。

首次选中的房间薄构件 `Componen2456 (C-Componen7142)` 在约 45 厘米范围内具有约 441 次 UV 重复。运行中断时已有 27,513 个高斯、382,225 个证书单元，但只认证了源面 0 的 3.22%，其他 11 个面尚未完成。该运行作为高重复 UV 压力测试保留完整队列与检查点，状态为 `incomplete`，没有纳入通过结果。见 [中断报告](../outputs/coverage_validation_20261103/interrupted_real_sk_00918_441_uv_repeats/interruption_report.json)。

首版保守保留无法证明隐藏的所有表面。有限足迹的连续几何覆盖不能保证任意相机下的屏幕 alpha 或无限尾部漏出；本次渲染结论限于上述案例与视角。本页记录的是初始化实验；后续已接入优化后无上限覆盖修复与重新认证，入口见 [coverage_sampling.md](coverage_sampling.md)。训练每一步的局部认证和完整场景重建仍未完成。
