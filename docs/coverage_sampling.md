实现见 [coverage.py](../mesh_to_gs/coverage.py)、[initialize_coverage_surface.py](../scripts/initialize_coverage_surface.py)。新入口不接受 `--budget`、`--max-budget`、`--max-growth`。`checkpoint_cells` 仅决定保存频率，不能结束采样。独立目标在任何高斯生成之前建立，保留全部非零面积面；无整片遮挡证明时不删除隐藏层，`visibility_report.json` 明确记录这一保守选择。

首版以共面、连通且 UV 连续的 chart 隔离支撑，材质及 UV 接缝两侧分别建模。使用最大物理间距初始化候选区域；不足区域补点，只有下界过松时细分验证单元。它没有按每个原三角形发放配额。源面曲率以更小共面片区表示，法线来自源面，不通过增厚替代覆盖。

凸共面 chart 的每条边施加协方差半平面约束，并按所有角点的最小 `sin(内角/2)` 缩小偏移，保证尖角的外侧斜接也位于欧氏误差带内。孔洞和非凸 chart 使用到全部边界的距离建立保守圆形渐变带；对数值极尖的三角形也使用此路径。中心落在实际缺口（包括边界和角点），横向尺度可以在正误差带内取正值。新足迹的边界构造使用至少 4σ 的安全半径，覆盖认证仍计入 3σ 有效支撑；额外收缩用于减小投影后普通尾部的叠加漏出，所需数量由补采样自然增加，最终仍需渲染验收。首版没有单独的预播边界样本阶段，边界由同一覆盖队列补齐。

先使用包含整个有效足迹的 UV 矩形，通过周期双线性纹理每个插值分片的角点求精确颜色范围；只有误差超过容差时才用纹理方向梯度指导协方差收缩，避免低幅度高频纹理造成不必要的微米级尺度。亚像素足迹的界可以继续收敛。共享 UV 边不代表相邻面的 Jacobian 相同：全 chart 近似共用一个仿射 UV 映射时，误差由全部角点证明；否则对实际可能相交的每个源面分别用其 UV 变换求界。排除不相交面使用凸二次型支持平面的距离下界，不能用近似最近点的距离上界误删候选。真正不同的 UV 边不合并。颜色阈值是单个 chart 的源纹理近似误差，不是最终多表面合成 RGB 的保证。最终合成质量另外渲染验收。

当前还缓存整张贴图的各通道最小／最大值，并为插值舍入误差向外扩张。周期双线性插值是原 texel 的凸组合：如果整图范围已经证明相对该高斯颜色的误差不超过构造容差，就无需重复扫描其 UV 足迹；否则保留上述精确局部查询。该捷径不改变覆盖阈值、颜色容差、候选范围或采样停止条件。

使用实际椭球 AABB 的完整 R-tree 查询；覆盖不允许无关薄层冒充。证书传播源重心坐标转换、坐标相减和白化运算的保守舍入误差。每个源面上的证书重心面积必须合计为 1，避免丢弃未验收区域后宣称成功。

边界几何验收证明每个有限有效足迹位于所属 chart 的误差带内，其并集在所有 chart 误差带之外的有效贡献上界为零。这里包含所有高斯，不通过剔除外来 chart 的贡献获得漏出结论。普通无限尾部、投影与屏幕滤波的漏出单独报告。

输出为标准属性名的 **float64 几何 PLY**，不再受大世界坐标 float32 中心量化影响；渲染器在 float64 中同时平移模型与相机后转为 float32。`coverage_report.json` 绑定最终 PLY 哈希，`surface/` 包含源面、保留状态、高斯对应、出生原因及完整子片证书。分组模型序列化后重新认证，合并 PLY 的 body 按字节复制；整体证书也合并保留，支持 [certify_coverage.py](../scripts/certify_coverage.py) 独立复查。

**现已支持优化后修复与最终认证。** `build_model.py --optimize` 执行覆盖初始化 → 联合优化 → 无数量上限修复。新模型的训练分裂选择所有达到梯度阈值的父点，不采用旧 2%／10% 上限；监督目标包含全部保留源面。未经修复的优化模型在 `intermediates/optimized/` 保留，其初始化证书明确失效。

修复入口 [repair_coverage.py](../scripts/repair_coverage.py) 按分裂 lineage 把每个优化点限制在其所属 chart，完整搜索 chart 的三角形并投影到最近位置。优化协方差投影回源切平面并重新施加间距、边界和精确颜色足迹约束；RGB 尽量保留在源中心颜色 ±0.5×颜色容差内。训练透明度低于初始上限时保持原值，高于上限时限制到 0.99，避免 gsplat 1.5.3 对接近 1 的贡献执行合成前提前终止而留下低 alpha。低透明度点可以通过合法重叠满足覆盖，不要求每个点单独超过覆盖阈值。所有原始目标从完整队列重新验收，实际不足才补点；序列化后复查空间覆盖、颜色和边界，并保存可恢复检查点。训练每一步的局部认证和失败回滚尚未实现。

## 目标与停止条件

允许删除已确认的隐藏重合层；其余保留的 Mesh 表面必须获得足够的高斯支撑，包括可见边界、接缝、薄片和细小结构。高斯数量是达到覆盖与质量要求后的结果。

新采样器不接受 `budget`、`max_budget` 或总高斯数量上限，也不按固定点数在不同区域之间竞争配额。后续修复不受“初始数量的若干百分比”或 `max_growth` 限制。分块大小只控制一次处理的数据量，所有未完成区域仍须处理。

成功停止须同时满足：

1. 每个保留表面单元都有连续区域覆盖证书。
2. 边界漏出、局部几何近似和颜色变化满足声明的误差要求。
3. 实际导出的参数经过重新验证，证书与模型、源几何和可见性协议的哈希一致。

内存不足或任务中断时保存进度，使用更小批次或外存继续。数值精度不足、约束冲突或无法完成证明时输出未解决区域及原因，状态为 `incomplete`，不能当作成功。去掉数量预算不意味着去掉质量阈值，也不意味着保证任意输入都能完成。

## 当前实现需要替换的机制

当前 [initialize_blend_surface.py](../scripts/initialize_blend_surface.py) 先从面积与重要性推导预算，再用 [surface.py](../mesh_to_gs/surface.py) 分配整数点数。最低配额针对 chart；同 chart 中的某些面可以没有样本。局部 kNN 协方差与边界收缩也没有形成覆盖证明。

现有默认边界规则要求垂直边界方向的 `2 sigma` 足迹不越界。它控制漏出，却可能降低边界支撑。现有 GPU 平面覆盖测试排除了边界，不能作为新目标的验收。

新的采样与验证应围绕表面区域工作。既有三角剖分用于定位和证明，一个高斯可以覆盖多个原始三角形；不采用“每个原始三角形至少一个高斯”的规则，避免让源 Mesh 的细分密度决定点数。

## 1. 独立建立保留表面

从 Blender 求值的世界坐标 Mesh 提取原始三角形、材质、UV 与几何邻接。保留非零面积的细长面；仅排除真正退化、无法定义表面的面，并逐项记录。不能沿用相对面积阈值直接删除仍有面积的薄小面。

先建立表面分区，再创建高斯。每个子片保存原始 face id、重心坐标顶点、chart 与可见性状态：

| 状态 | 处理 |
| --- | --- |
| 已发现可见部分 | 纳入覆盖目标；需要时继续划分部分遮挡区域 |
| 已证明整片属于隐藏重合层 | 允许剔除，保存证据 |
| 无法可靠判定 | 保守纳入覆盖目标 |

可见性使用独立的自由空间观察点协议和完整源 Mesh 的遮挡查询，不能用“有没有采样点”或“还有没有高斯”定义保留范围。现有 [visibility.py](../mesh_to_gs/visibility.py) 的射线工具可用于寻找可见证据；中心和几个探针都被遮挡，不能证明整个子片都被遮挡。

删除整片需要覆盖整片的遮挡证据，例如投影遮挡多边形及其深度次序，且需符合近距离重合层规则。首版无法提供这类证据的区域保留，不能以全体探针未命中替代证明。部分遮挡面须划分为子片，避免整面误删。

有限观察点无法证明所有可能相机位置的不可见性。输出须明确观察点协议及其适用范围；新增观察点后重新评估被剔除区域。保留表面集合一经建立，之后不会因高斯被删除而缩小。

## 2. 用质量要求定义局部采样间距

低细节区域使用最大世界间距 `h_max`，它是空间质量要求，不用于计算总数量。纹理、曲率和细小结构可以使局部间距更小；覆盖失败仍会触发额外采样。

纹理结构张量继续在 scene-linear RGB 中计算，经 UV-to-world Jacobian 转为世界切平面单位。沿两个主方向分别确定允许间距：颜色变化快的方向更密，变化慢的方向可较疏。曲率、法线变化和薄结构进一步限制允许的切平面区域。不得用低分数区域的减配额去补偿高分数区域的加密。

例如，若方向上的线性颜色梯度估计为 `g_j`，可用 `h_colour,j = epsilon_colour / max(g_j, epsilon)` 产生初始间距，再与 `h_max` 和几何约束取较小值。它只指导初始采样；mip 梯度与有限纹理探针不是严格的颜色误差上界。最终颜色验收还须检查原纹理在单元与足迹内的变化。

单元划分按实际世界几何和该方向度量进行，沿物理长度或度量长度最大的方向细分。划分不会强制创建高斯；已有支撑能够证明覆盖的单元可以直接复用。

## 3. 先处理边界与接缝，再覆盖内部

真实外边界和孔洞使用专门的采样带：

- 在实际边界上放置样本，沿边界方向按局部质量间距采样；拐角与端点单独处理。
- 边界高斯长轴沿边，横向尺度由允许的轮廓误差约束。
- 在边界与内部之间建立渐变采样带。越接近边界，横向间距越小；到边界时以正的空间精度要求为尺度，避免无限细分。
- 每个相邻材质／UV 分区维护自己的颜色对应；不能平均颜色后跨接缝抹平细节。

共面连续的材质／UV 接缝不是外轮廓。可允许两侧支撑在确认的连续几何范围内重叠，但分别检查颜色。硬边、薄片的另一层、空间靠近但不连通的表面不能冒充本片的支撑。

内部从未覆盖单元中选点，中心落在对应源 Mesh 上。已有支撑足够的单元不再加点；新点根据局部间距、几何和纹理方向构造协方差。kNN 可以改善形状估计，但不能成为覆盖判定或足迹大小的唯一依据。

初始法线使用对应 Mesh 子片的几何法线，纹理方向调整限定在切平面内；初始法向厚度沿用短切向尺度的 2%。跨曲面的大足迹若不能满足几何误差或覆盖要求，应划分更小片区，不能通过增厚掩盖失配。每个新点仍保存确切 face、重心坐标和该位置的 UV 颜色。

### 边界上的必要取舍

普通正定高斯的贡献连续。不能要求边界处支撑至少 0.95，同时要求边界外任意近的位置贡献立即为零。必须声明正的轮廓误差带，或改用裁剪支撑的表示；本方案采用普通高斯及明确的误差带。

例如单个边界高斯在边界处 opacity 为 `a`，横向标准差为 `sigma_perp`，要求距离 `delta_edge` 处贡献不超过 `epsilon_out`，则：

`sigma_perp <= delta_edge / sqrt(2 * log(a / epsilon_out))`。

该式只约束单个高斯；多个高斯叠加后的漏出必须另外检查。边界高斯不能再使用“中心到边界距离 / 2”的尺度上限，否则中心位于边界时尺度会归零。

## 4. 为连续表面建立覆盖证书

覆盖定义为有限有效足迹内的几何支撑强度，不能以高斯的无限微弱尾部算覆盖。它不是相机下的渲染 alpha，二者分别验收。

对高斯 `i`，使用实际中心 `mu_i`、协方差 `Sigma_i` 和 opacity `a_i`：

`q_i(x) = (x - mu_i)^T Sigma_i^-1 (x - mu_i)`。

定义有效支撑半径 `r_support`，只计入 `q_i(x) <= r_support^2` 的贡献：

`u_i(x) = a_i * exp(-q_i(x) / 2)`，足迹外为零；

`A(x) = 1 - product_i(1 - u_i(x))`。

目标是在每个保留表面上满足 `A(x) >= tau_cover`。候选贡献还须符合几何片区归属规则，避免旁边另一张薄片或已剔除层掩盖本片缺口。

### 子三角形的保守下界

对顶点为 `v0, v1, v2` 的子三角形 `T`，因为 `q_i` 是凸二次型：

`Q_i = max(q_i(v0), q_i(v1), q_i(v2))`

是整个三角形上的能量上界。取：

`l_i = a_i * exp(-Q_i / 2)`，当 `Q_i > r_support^2` 时取零。

则整个子三角形的覆盖下界为：

`A_lower(T) = 1 - product_i(1 - l_i)`。

只有 `A_lower(T) >= tau_cover` 才给出整片覆盖证书。这不是“分别检查三个顶点”：同一组高斯对整片都提供声明的最低贡献，所以三角形内部也受约束。多个高斯分别覆盖不同顶点并不能直接证明内部没有孔洞。

下界不足不等于真实漏覆盖，也可能是单元太大导致界太保守。先扩大候选查询，必要时细分验证单元；细分本身不增加高斯。对实际不足的区域再补点或调整足迹。

在 float64 中计算能量并保守处理舍入误差。使用实际协方差和法向厚度，不能把训练 loss 中额外的 normal tolerance 偷换成采样覆盖证明。极薄面与大世界坐标需特别核对 PLY 的 float32 量化；必要时设计局部坐标输出及显式场景变换。

构造时留出正的覆盖余量，例如目标支撑 0.96、认证阈值 0.95，避免真实最低值恰好位于阈值时不断细分仍无法证明。余量是数值与质量参数，不是采样数量限制。子片细分到当前坐标表示无法区分时，须报告精度问题，不能跳过该片。

### 完整候选查询与漏出验收

用有效椭球的 AABB 建立 BVH，按单元查询所有相交候选，再过滤不合法的几何片区。不固定为最近 12／32／64 个中心；大足迹高斯也可能有贡献。遗漏候选会让下界更保守，不能因此直接判定必须加点。

真实外边界／孔洞外的允许误差带之外，建立外侧验证单元；完整源 Mesh 查询需先排除实际属于其他表面的区域。对外侧单元，可由每个高斯在单元上的最小二次型获得其贡献上界，再组合为总支撑上界。上界过宽时继续划分，直到证明满足 `epsilon_out`，或识别真实漏出并修复。

覆盖下界可以使用合法贡献的子集，遗漏只会降低下界；外侧总贡献上界必须包含所有可能贡献的高斯，包括来自其他片区的高斯，不能遗漏或按归属过滤掉真实漏出。候选完整性是外侧验收通过的必要条件。

外侧验证只约束声明的几何域与误差带；任意视角的渲染轮廓还受投影、遮挡和屏幕滤波影响，不能由这份几何证书推出。

## 5. 无数量上限的局部修复闭环

建立未验收单元队列，先处理明显缺口、边界和薄结构；之后处理界限不确定的单元。优先级只决定处理顺序，不限制最终处理数量。

```text
target = 从源 Mesh 独立建立保留表面与边界
samples = 边界采样带 + 按局部质量间距产生的内部种子

while 存在未验收单元:
    cell = 取出一个单元
    candidates = 查询实际有效足迹与 cell 相交的合法高斯
    if 连续覆盖下界、颜色和几何要求全部满足:
        保存 cell 证书
        continue
    完成候选查询，在顶点／边中点／内部位置检查实际支撑
    if 未发现真实不足，但连续覆盖下界仍未通过:
        细分 cell，继续证明；此步不创建高斯
        continue
    if 现有足迹有满足质量与漏出约束的调整空间:
        调整足迹
    else:
        在实际不足的区域补充 Mesh 样本，读取该位置 UV 颜色
    使受影响单元证书失效，重新加入队列

检查外侧漏出与颜色误差
若修复改变参数，重新检查受影响的覆盖单元
序列化模型，再验证实际导出参数与全部目标单元
```

调整时先利用合法重叠改善覆盖，足迹不能无限放大。纹理细节限制、几何约束或轮廓误差阻止扩大时，新增采样；不靠增大法向厚度、抬高 opacity 上限或跨薄片混合掩盖缺口。

某些区域可能因参数化或数值精度无法满足要求。此时给出具体约束冲突，保留待处理单元与检查点；不能无条件循环或把进度上限转换为“覆盖通过”。

删除样本、调整中心／尺度／旋转／opacity，以及纹理协方差变换都会使局部证书失效。使用旧足迹与新足迹的影响域并集查找需复验区域；新增高斯不会降低合法贡献下界，但仍需检查漏出和颜色。

## 6. 参数、输出与运行方式

第一轮受控验证可从以下参数开始，它们是待验证的质量协议，不是已验证默认值：

| 参数 | 初始建议 | 含义 |
| --- | ---: | --- |
| `coverage_threshold` | 0.95 | 保留表面的最低几何支撑 |
| `support_radius_sigmas` | 3 | 计入覆盖的有效足迹半径 |
| `opacity` | 0.99 | 初始单点 opacity |
| `max_spacing_world` | 0.024 m | 低细节区域最大初始间距 |
| `colour_error_linear` | 0.02 | 初始纹理变化容差，需控制实验核对 |
| `plane_error_world` | 0.0001 m | 局部切平面近似的误差目标 |
| `edge_tolerance_world` | 0.001 m | 真实外边界允许的几何误差带 |
| `outside_support_threshold` | 0.05 | 声明外侧域中的最大支撑 |

`max_spacing_world` 只给初始空间分辨率，不能阻止覆盖所需的进一步加密。边界误差按世界单位声明，并报告测试相机下对应的像素影响。模型数量、耗时和内存用于记录成本，不是采样停止参数。

输出至少包含：

- `model.ply` 与需要时的局部坐标变换。
- 独立的表面分区：源 face、子片重心坐标、材质／UV／几何归属、保留或剔除状态。
- 高斯对应：出生位置、源 face 与 UV、修复原因，以及跨连续接缝的合法支撑关系。
- `visibility_report.json`：观察协议、隐藏子片证据及不确定保留区域。
- `coverage_report.json`：阈值、模型哈希、目标区域、最小认证下界、证书数量与未解决区域。
- 边界／颜色／几何验收及各阶段自然生成的高斯数量；中断后可恢复的检查点。

报告须把“实际失败”和“尚未证明”分开。已认证面积、待认证面积、剔除面积分别记录；任何非空保留区域未验收，整体状态就不是成功。

## 7. 与仓库训练流程衔接

初始化覆盖证书只属于它验证过的模型。现有联合优化允许移动中心、缩放、旋转与改变 opacity，常规双子分裂也不保持证书。

已实现的流程在联合优化结束后重建完整验证队列，依据实际缺口补采样；训练分裂与最终修复均不受每轮 2% 或总增长 10% 限制。有限 batch 可以逐批处理所有缺口。纹理方向调整整合到足迹构造／修复中，不能在最终认证后再静默改变协方差。每次训练拓扑变化后的即时局部认证仍属后续扩展。

训练内部可以暂时处于未认证状态，但需记录。最终导出前必须重新认证、修复并复核完整保留表面；若要求训练每一步都保持覆盖，则需额外实现更新后的局部验证及失败回滚，不能只依赖 Mesh loss。

[mesh_supervision.py](../mesh_to_gs/mesh_supervision.py) 也要从独立保留表面采样，不能继续用 `charts[row_faces]` 定义被监督的全部目标。动态邻点仍可近似训练 loss，最终认证使用完整足迹查询。

## 8. 实施与验收顺序

1. 实现独立目标分区和连续区域证书，在当前初始化结果上定位缺口；确认验证细分不会强制增加样本。
2. 实现无预算的内部覆盖采样与局部修复，覆盖平面、重三角化、细长面和相近双层面。
3. 实现真实边界、孔洞和连续接缝采样带，联合检查覆盖、漏出与颜色误差。
4. 整合纹理／几何方向约束、可见性证据、外存检查点和实际导出复核。
5. 接入新的构建路径，再对两个完整场景运行初始化与联合优化验收。

受控检查须包含内部、完整边界、端点／拐角和细结构；不把轮廓附近像素从覆盖结果中删掉。验证单元的证书检查与独立稠密探针同时保存，探针只用于发现实现错误，不能替代连续区域证明。

重三角化、细节区域增密、原生薄片和可见性部分遮挡需单独验证。随机探针、固定 kNN 或浮点量化的问题不能被“平均覆盖率接近 100%”掩盖。中断恢复后的证书也需核对模型版本及哈希。

真实渲染沿用同相机的无光照 Mesh 参照与线性白背景合成，分别报告前景内部、轮廓带和小结构的 alpha、深度及颜色。记录最差视角、未覆盖位置和额外高斯数量；几何支撑认证不等于已经保证所有视角渲染 alpha 都达到 0.95。

本方案最终以覆盖与误差验收决定数量。点数和计算成本是方案结果，不能通过截断数量改变声明的覆盖目标。
