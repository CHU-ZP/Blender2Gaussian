# Mesh 区域重采样消融记录

归档日期：2026-11-03。最终决定：两个场景均只保留原方案 `views72_priority1500`，即 72 视角优先采样、1500 步、允许中心移动、交错常规分裂、固定法线。当前方法见 [best_pipeline.md](best_pipeline.md)。

四组实验的方法、逐种子数值、冻结参数／输入与源码哈希、耗时及审计摘要保存在本文和 [机器可读记录](results/resampling_ablation.json)。其他方案的实现、测试、源码快照、模型、渲染、日志及初始化／查询缓存均已删除；本文是历史记录，不提供已撤销的运行入口。记录中的源码和模型哈希标识当时的实验，不表示这些实验文件仍保留或当前源码未改变。

本次两个场景、两个种子的结果没有支持“只把分裂位置改为区域重采样就能普遍改善”。C 相对 A 的全部独立测试 PSNR：房间 +0.0166 dB、家具 −0.0418 dB；固定细节 ROI 分别 −0.0963／−0.3640 dB。房间整体的小幅提升与家具整体下降都在两个种子中同号。B 相对 A 的房间收益随种子变号，家具两个种子均下降。

D 相对 A：家具整体 +0.4790 dB、挂饰／画作 ROI +0.6341 dB，两个种子均改善；房间整体仅 +0.0339 dB，墙面文字 ROI 则 −1.3841 dB，两个种子均下降。D 同时重新初始化颜色／先验及协方差，本次对比无法拆分各自贡献。D 的不透明覆盖和深度一致覆盖提高，但深度外溢增加，房间深度 MAE 也略增。综合细节质量、额外计算和维护成本，最终选择原方案；D 在家具上的较高均值仍如实记录。两个种子不足以作统计显著性或跨场景泛化结论。

| 组别 | 创建子点的位置 | 颜色／UV 先验 | 切向尺度／面内旋转 |
| --- | --- | --- | --- |
| A_split | 原长轴分裂，偏移 ±0.5 sigma | 继承父点 | 父尺度除以 1.6，继承旋转 |
| B_project | 将 A 提议的位置投影到原 chart 的 Mesh | 继承父点 | 同 A |
| C_resample | 在 A 选中区域内重采样两个 Mesh 点 | 继承父点 | 同 A |
| D_reinit | 与 C 相同的新位置 | 读取新位置的 Mesh UV BaseColor，并重置先验 | 按局部点间距／协方差重新初始化 |

两个场景、两个训练种子 `20261102`／`20261104`，共 16 次训练。每次使用固定的 72 个训练视角、1280×720 图像、1500 次 Adam 更新，在第 100／200／300／400 步优化后创建子点；每轮最多选择初始数量的 2% 父点，每个父点替换为两个子点，净增约 8%。其余联合 loss、学习率及可训练参数见 [joint_quality.json](../configs/joint_quality.json)。四组均继承并固定初始法线，法向厚度为短切向尺度的 2%。

A 按在线图像 loss 与参照高频细节优先抽取相机；B／C／D 重放 A 实际访问的相机、Mesh 表面／空空间批次、中心约束行，以及各次选中的父点行。这样不会把训练视角变化或分裂区域变化混入几何策略对比。新组各自优化其参数，并重建其动态邻点。

B 对 A 的长轴分裂位置做原 chart 内最近三角形投影。C 为每个父点生成 16 个候选：11 个位于父点切向椭圆的一个 sigma 范围内，另 5 个位于祖先点附近，主候选不足两个时才启用后者。候选需满足原 chart、继承法线轴与面法线轴夹角不超过 20°（点积取绝对值）、既有祖先中心运动界等约束；没有可行候选时保留末尾祖先候选，显式记录放宽筛选的行数和重复点。按到附近存活高斯及已选第一个子点的距离进行贪心 max-min 选择；附近距离使用全局 kNN 的最多 16 个候选，再筛选同 chart，属于局部间距启发式。

投影／重采样发生在四次增密事件的出生位置，之后四组仍允许中心优化，由共同的联合 loss 和中心约束控制；它们不保证最终中心严格位于 Mesh。

D 在相同 C 位置按附近存活点和同轮新点的 12 邻域估计切向协方差，轴比上限 4，尺度在常规子尺度的 0.5–2 倍内；另保留满足祖先运动界所需的尺度下限。面内旋转限制 ±45°。D 同时重置 RGB、UV 先验和切向协方差，因此 D−C 测量的是整体重新初始化收益。

UV 取样使用新点到所属三角形的三维最近点及对应重心坐标。极细三角形上先比较面内投影与三条边的世界距离，避免直接截断重心坐标造成 UV 沿长边偏移。几何审计也使用实际三维最近距离；新增回归测试覆盖浮点量化后的极细三角形和边界取样。

C／D 的位置以及 D 的协方差计划统一从 A 的父点区域、存活点和同轮新点生成；其他组重放这些计划。比较因此针对共同基线区域内的策略变化。D 会同时更新尺度参照及相关运动／尺度界，原始祖先中心锚点保持一致。

评估使用两个场景各 16 个独立测试姿态，分别报告原测试与新测试各 8 个姿态，训练姿态不进入测试。完整相机姿态比较确认：72 个训练姿态、16 个测试姿态各自无重复，两集合无重叠；审计记录已并入机器可读文档。固定细节 ROI 在训练前锁定：房间墙面文字 `[.05,.20,.95,.80]`，家具挂饰／画作 `[.15,.08,.95,.92]`，均为归一化坐标，每场景原／新测试各一个 ROI。整体 PSNR 为各测试视角不透明 Mesh 像素（Mesh alpha ≥0.99 且深度 >0）PSNR 的等权平均，细节 PSNR 为两个固定 ROI 的等权平均；结果报告两种子的均值、样本标准差，以及 B−A、C−B、D−C、C−A、D−A 配对差值。

实验当时在输入准备后冻结协议和 32 个源码文件的哈希，完成训练后检查实际训练输入哈希、父点行、子点出生参数、C／D 相同位置、祖先 lineage、原 chart、固定法线、有限参数和渲染输入。协议、出生统计与审计摘要已归档；实验期间通过的源码一致性检查不用于清理后的源码。

审计表中的 Mesh 距离只针对 B／C／D 的出生位置；候选回退和近重合对子按两种子的 C／D 共同计划统计，不重复计算两组。无可行候选时的回退可能放宽运动或法线筛选，仍保持原 chart。间距小于 `1e-7 m` 的对子为房间 670 对（占选择父点的 0.055%）、家具 827 对（0.223%）；筛选回退分别 12／15 行。这些退化情况保留在记录中。

## 与保留基线的复现差异

重新生成的初始化／纹理协方差模型、查询文件哈希与保留训练缓存一致，训练参照和相机沿用保留文件，但相同种子 `20261102` 的新 A 并未逐字节复现旧 best。下表记录新 A 减旧 best 的 PSNR；四组配对结论均以本次 A 为参照，复现差异的具体来源尚未单独定位。

| 场景 | 原测试差值 / dB | 新测试差值 / dB | 全部测试差值 / dB |
| --- | ---: | ---: | ---: |
| 房间 | −0.0469 | −0.0715 | −0.0592 |
| 家具 | +0.0065 | −0.0409 | −0.0172 |

完整对照、模型哈希及标量配置差异见机器可读文档的 `baseline_reproduction`。旧报告的 `query_count=262144` 是当时 CLI 值，实际缓存每类含 1,048,576 条；本次声明并使用实际缓存数量，查询数据文件哈希仍完全相同。

首轮因极细三角形 UV 重心坐标的数值问题作废，最终结果只使用修正后 v2 的全部 16 次重跑。当时 96 项测试、四组 GPU 短程验证及全量审计通过；这些是实验时期的验证数量，清理后的测试数量另记。批量几何回归检查房间 4,853,664 个出生点、家具 1,483,328 个出生点，最大 Mesh 距离分别为 5.30e-7／2.63e-7 m，重心重建误差为 2.89e-12／1.22e-12 m。

一次任务中断停止了尚未保存最终模型的四个训练进程；它们在相同协议和控制下从头重跑，最终全部完成。清理前 v2 复用了首轮输入缓存；本次同时删除两轮实验目录及其缓存、快照和日志，best 模型及其独立参照不依赖这些文件。

## 优化耗时

以下为日志中的优化循环秒数，四组均为两种子均值，原 best 为其原始单次训练。准备、导出和测试渲染不计入优化循环；逐次准备／优化／总时长及 GPU 信息已归档。

| 方案 | 房间 / 秒 | 家具 / 秒 |
| --- | ---: | ---: |
| 原 best 常规分裂 | 280.917 | 294.781 |
| A_split 实验基线 | 399.853 | 362.327 |
| B_project | 281.416 | 269.525 |
| C_resample | 277.944 | 320.266 |
| D_reinit | 284.489 | 274.049 |

A 在训练过程中生成所有组共享的投影／重采样／协方差计划，B／C／D 读取计划；共享计划平均耗时为房间 106.250 秒、家具 60.912 秒。因此表中 A 不是只做常规分裂的独立计时，不能据此宣称 B／C／D 比原方案更快。训练运行在共享硬件上，存在并发和负载差异，未完成相同 GPU／相同负载的公平速度基准。

原 best 优化约 4.68／4.91 分钟。D 循环加共享计划的粗略成本参照约为 390.739／334.961 秒（6.51／5.58 分钟），并非实测独立 D 流程；当时 D 的运行入口还依赖完整 A 训练。选择原方案考虑了这部分计算与维护成本，不能把这些历史计时当作精确速度排名。

## 早期联合优化消融

以下为清理前用户提供的早期实验记录，单位 dB。其评估口径不同于本次 16 个独立测试视角，不与上述数值直接比较。

| 方案 | 房间 / dB | 家具 / dB |
| --- | ---: | ---: |
| 仅 render，移动＋分裂 | 25.458 | 25.699 |
| 联合 loss，固定中心 | 25.499 | 24.595 |
| 联合 loss，允许移动 | 25.778 | 25.307 |
| 联合 loss，移动＋分裂 | 25.518 | 24.965 |
| 再允许法线改变 | 25.573 | 25.061 |

这些对照分别改变 Mesh 监督、中心自由度、分裂开关和法线自由度。后续调整训练视角、步数及分裂顺序，最终保留 72 个视角按 loss／高频优先抽样、1500 步、第 100／200／300／400 步优化后分裂，再继续固定拓扑优化。早期的“先分裂再集中优化”入口已撤销；本文只记录已知数值，不补造缺失的逐次训练结果。更早的初始化／渲染口径实验见 [experiment_history.md](experiment_history.md)。
