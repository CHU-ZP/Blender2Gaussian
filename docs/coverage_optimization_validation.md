## 训练和验证协议

沿用 [初始化实验](coverage_sampling_validation.md) 的四个受控案例和两个真实局部构件：平面、带孔平面、3 毫米薄片、棋盘纹理、房间面板和脚轮叉架。每个案例新增 12 个训练相机，保留原来的 3 个测试相机；没有使用测试图像训练或回投测试像素补点。

每个初始化运行 1500 步，种子为 20261104，分辨率 640×480，A100 GPU 1。位置、切向尺度、面内旋转、RGB 和透明度可优化，法线固定。损失和学习率来自 `joint_quality.json`。新旧两组使用相同相机、Mesh EXR 和逐项完全相同的表面 GT：每类查询 16384 个，表面按所有保留源面的面积采样；训练池每类 8192 个，表面／空域 batch 各 1024 个，中心 batch 1024 个。空域查询围绕各自初始化足迹生成，在线视角优先级和分裂选择随模型变化，结果反映相同协议下的完整流水线。

两组都选择全部达到 `2e-5` 屏幕梯度阈值的父点，在第 100、200、300、400 步分裂，**没有每轮比例或总数量增长上限**。旧初始化保留为对照；新采样、训练分裂和最终修复均没有点数预算。训练步数、batch 与认证批处理大小只决定训练或计算方式。

比较五个模型：旧初始化、旧初始化加优化、新覆盖初始化、新初始化加优化、优化后最终修复。所有未经修复的优化模型及其失败证书、探针、RGB／alpha／depth 渲染都保留。

覆盖、颜色和边界质量参数沿用初始化实验：连续空间支撑下界 0.95、构造探针目标 0.98、3σ 有效支撑、至少 4σ 边界构造、1 毫米边界误差带。实验颜色容差为线性 RGB 的 **0.08**，生产默认仍为 **0.02**。完整前景与轮廓带分别统计，普通无限尾部在投影后的边界误差带之外要求最大 alpha≤0.05。

## 优化后修复

[repair_coverage.py](../scripts/repair_coverage.py) 按分裂 lineage 保存原 chart 归属，完整搜索该 chart 的源三角形，投影中心并重建对应 face／重心坐标。优化协方差投回源切平面，再施加间距、边界、曲率和精确纹理足迹约束。RGB 尽量保留在源中心颜色 ±0.5×颜色容差内。透明度低于 0.99 时保留，高于 0.99 时限制到该上限。

重新建立全部源面目标队列，实际支撑不足才新增点；仅下界过松时细分证明单元。实际导出的 float64 PLY 重新认证，独立探针不能替代连续区域证明。验证批量计算保留每个单元的全部 R-tree 候选；与逐单元计算的下界一致。恢复前核对源文件、优化模型和 lineage 哈希；同一输出加文件锁，独立案例可以并行处理。

## 透明度提前终止问题

gsplat 1.5.3 在 `next_T<=1e-4` 时，会在合成当前贡献之前退出。接近 1 的训练透明度可能使尚未达到 0.95 的像素提前退出。两个同像素高斯的最小验证中，透明度为 0.91／0.9999，理论 alpha 为 0.999991，实际为 0.910000；限制为 0.91／0.99 后，实际 alpha 为 0.999100。

当单次贡献最多为 0.99 时，提前退出只会发生在之前的透射率≤0.01，即像素 alpha 已经≥0.99。最终修复应用该上限并重新补足覆盖；没有整体重置为固定透明度。首轮平面修复模型、图像、指标与证书保存在 `plane/*_before_opacity_guard*`，原实验汇总保存在 `validation_before_opacity_guard.json`。

## 适用范围与运行方式

联合优化的有限邻居支撑损失仍是近似。新模型的 32 候选与 512 候选对照中，最大 alpha 差异为 0.371–0.998；这个对照也不是全足迹证明。训练 loss 不能替代最后的完整认证。原初始化颜色已经接近 Mesh，训练颜色与位置的变化可能增加误差；最终流水线差异包含投影、协方差限制、颜色限制、透明度上限和补点的共同影响。

本实验覆盖单个种子、六个局部案例和固定测试相机。两个完整场景以及之前的高 UV 重复压力案例不在这次训练验证范围内。原源资产、best 模型和旧采样实验保留。

```bash
uv run --no-sync python scripts/validate_coverage_optimization.py \
  --output-dir outputs/coverage_optimization_new --gpu 1 \
  --summary-output docs/validation/coverage_optimization_new.json
# 完成案例复用；修复阶段保留完整队列，可从中断恢复
uv run --no-sync python scripts/validate_coverage_optimization.py \
  --output-dir outputs/coverage_optimization_20261104 --gpu 1 --resume \
  --summary-output docs/validation/coverage_optimization.json
```
