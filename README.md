# Mesh → Gaussian 批量训练

从带 Mesh 和材质的 Blender 场景自动生成 SH0 Gaussian PLY。将输入放在一个目录中，执行一条命令即可完成采样、渲染参考图、训练和验证。

## 运行

运行环境为 Linux x86_64，需安装 uv、NVIDIA 驱动、CUDA Toolkit 12.8（含 nvcc）及 C++ 编译器。首次启动时，uv 根据锁文件安装 Python 3.13 与依赖，gsplat 首次渲染时会编译 CUDA 内核。自定义 Toolkit 路径可通过 `CUDA_HOME` 指定。

```bash
./run_batch.sh /path/to/blend_scenes --output-dir /path/to/results --gpus 0
```

程序递归发现输入目录中的 `.blend` 文件，也接受场景路径的 JSON 数组。清单内的相对路径从清单所在目录解析。外部纹理需保留可访问的资源路径，或在 Blender 中打包。多卡可写 `--gpus 0,1`，每卡同时处理一个场景。添加 `--dry-run` 可先查看每个场景的运行计划。

## 默认流程

1. 按世界空间表面积和目标间距一次生成高斯，初始数量约为有效面积除以间距平方。默认间距为 **0.024 世界单位**，在以米建模的场景中即 **2.4 cm**。三角形内部随机采样，最近邻距离会有波动。
2. 按三角面数估算训练视角、验证视角和训练步数。预留验证相机，再按几何可见性选训练相机。训练和验证参考图均采用 **Blender Cycles、PBR v10、1280×720、自适应采样上限 16 样本/像素**。
3. 按材质校准透明度，先训练颜色和透明度，再优化绑定在原三角形上的高斯，并对不透明区域施加深度监督。基础 SH0 模型通过参数审计后，尝试多视角局部修色。只有验证视角的整图和局部 MAE 均下降、整图 MSE 也未上升时才采用修色结果。

## 结果和续跑

成品为 `scenes/<场景名-路径哈希>/model.ply`，这是指向选定模型的相对符号链接。单独复制成品时用 `cp -L`。批次根目录的 `batch.json` 汇总场景状态、模型路径和 SHA256，`logs/` 保存逐场景日志。

在同一机器上使用相同输入路径和输出目录再运行，会从第一个未完成的阶段继续。更改渲染或训练参数时，请指定新的输出目录。

## 自带示例

这条命令保留正式采样间距和 Cycles 16，缩小图像、视角数和步数，便于验证安装。

```bash
./run_batch.sh examples --output-dir outputs/example --gpus 0 \
  --views 6 --validation-views 3 --steps 28 --width 96 --height 64
```
